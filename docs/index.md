# Intro

 A second iteration of a DOS-inspired hobby OS. Written in Rust and x86 assembly. It boots, runs, executes, schedules, renders and does networking.

 Check it out on [Github](https://github.com/krustowski/rou2exOS)!

![memento-welcome](assets/r2-memento-start-screen.png)

*Fig. 1: The initial screen of the `MEMENTO` GUI experiment. The screen is shown right after the boot (if configured in the init script so). That "thing" on the right is the mouse cursor ready to be moved by a PS/2 mouse.*

![memento-desktop](assets/r2-memento-desktop-v0.11.5.png)

*Fig 2: The Desktop window showing a variety of some "programs" available to run in `MEMENTO`.*

![memento-login](r2-memento-hello-login.png)

*Fig. 3: External userspace program demo called `MEMENTO.ELF`. Login window in the foreground, a wallpaper in the background.*

![memento-clock](assets/r2-memento-clock-window-v0.11.5.png)

*Fig. 4: The Clock window in the `MEMENTO` GUI experiment.*

Userland programs are static ELF64 binaries. Each one runs in ring 3 in its own private 2 MiB frame mapped at `0x600_000` and calls into the kernel via interrupt `0x7F`. Programs can be written in C, C++ or Go (TinyGo) using the libraries of the [SDK](sdk/index.md).

![kernel-shell-init](assets/r2-kernel-shell-init-script-output-v0.11.4.png)

*Fig. 5: Kernel shell init. The verbose output is generated by just-started external applications. The `INIT.RC` script file is parsed and executed by the shell command interpreter.*

It boots via GRUB/Multiboot2, runs in 64-bit long mode with a custom identity-mapped page table, and exposes a kernel shell backed by a preemptive round-robin scheduler running at 1000 Hz. 

The kernel speaks directly to the hardware: 

+ ISA DMA for floppy I/O (FAT12, read/write, with a track cache), 
+ ATAPI PIO for CD-ROM (ISO9660, read-only; carries the shipped programs in `/bin`), 
+ an RTL8139 NIC for Ethernet/TCP networking, 
+ a VESA framebuffer or VGA text mode for output, plus VGA mode 13h for userland,
+ a PS/2 keyboard and mouse,
+ the PC speaker (tones and Standard MIDI Files). 

## Releases

To run the latest release of the kernel (`r2.iso`) and the aux floppy image (`fat.img`), just visit link below and download both files to your machine. The ISO carries the kernel and the userland programs; the floppy carries the startup script, configuration and data.

+ [Releases on github.com](https://github.com/krustowski/rou2exOS/releases)

Please consult the [Build & Run](build.md) page to see options on how to run the system in QEMU locally.

```
qemu-system-x86_64 -boot d -cdrom r2.iso -fda fat.img
```
